J-me settings

Three choices. Everything else is the switch on the tab.

Which AI a card hands off to

Every card has an "Ask …" link that opens the question in your own AI, in your own account.

Answer inside J-me (optional)

With your own API key, every card gets an Answer here button and the answer appears in the card, while the video keeps playing. The key stays on this machine; only the question and the moment that raised it go to the provider, and only when you press the button. "Custom" is any OpenAI-compatible server, such as Ollama or LM Studio on this machine (no key needed).

Your documents (optional)

Choose a folder of your own files (notes, minutes, contracts, specs: .md, .txt, .html, .json, .csv). J-me reads them once, keeps the text on this machine, and every card searches them before the web. Choose the folder again after you change the files.

Share with a local agent (optional)

Sends the transcript and the cards to a small program on this machine, so your own agents can read them and ask questions into the queue. Run node engine/src/mcp.ts from the J-me folder; it is an MCP server for Claude Code, Codex, Cursor or Cortext. Nothing leaves the machine. See docs/AGENTS.md.

Where the cards show

Clicking the icon opens J-me in the browser's side panel, beside the page. Drag the panel's edge to make it as wide as you like, half the screen if you want.

Microphone

For a call in another app (Zoom, Teams, the room): switch the microphone on in the J-me side panel. Chrome asks for permission once, here.

Brain

Automatic tries Ollama on this machine, then the browser's built-in model, then a small model inside the browser. Pick one to force it.
